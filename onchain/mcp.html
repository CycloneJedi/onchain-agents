Project OnChain / MCP server

Connecting the OnChain MCP server

A draft open-source MCP server (stdio, MIT), test chain only, not published, that wraps OnChain's one-call agent tool, so an MCP-capable agent can open and manage a deal with one tool call per step. It is not published to any registry yet. Source today: /workspace/onchain/tools/mcp-server (local).

Current scope (read before relying on it)

  • The server currently refuses any chain id other than 31337 (local test chain). Base Sepolia support for this testnet set is not in the server yet.
  • Its high-level tools (open_deal, fund, release and others) cover escrow, milestone, split and bounty builds. Newer builds are reached through versioned_schema and versioned_call with an explicit contract address. Pay-per-use v1.9, stream v2.0, split v3.1 and job board v3.0 are not listed as supported builds in its README yet.
  • Job board v3.0 via MCP: live on Base Sepolia for reading and explaining deals (test network, test token, not audited). Skipping a bid through MCP is local-only for now; use the contract calls on the job board page to skip on testnet. The buyer may pass over any candidate, including the lowest bid; the lowest bid is not guaranteed to win; every skip is recorded publicly.
  • Dry run by default. Sending needs dry_run=false, an explicit rpc and confirm=true.
  • Keys are resolved locally from environment variables or a key file and are never accepted or returned by a tool. Use test keys only.

Setup

cd onchain/tools/mcp-server
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt   # mcp 2.3.0, web3 8.0.0, eth-account 0.14.0
.venv/bin/python -m onchain_mcp.server      # stdio MCP server

Client config (Claude Desktop / Cursor style)

{"mcpServers": {"onchain-oneshot": {
  "command": "/path/to/onchain/tools/mcp-server/.venv/bin/python",
  "args": ["-m", "onchain_mcp.server"],
  "cwd": "/path/to/onchain/tools/mcp-server",
  "env": {"ONESHOT_TEST_KEY_FILE": "/path/to/test-accounts.local"}}}}

Tools

Reads: list_templates, quote_deal, get_deal_status, list_sub_deals, get_fee_bond, versioned_schema, arbiter_acceptance. Sends (dry run unless confirmed): open_deal, accept_offer, counter_offer, approve_funding, fund, deliver, release, dispute, arbiter_rule, claim_timeout, refund, cancel_unfunded, withdraw, open_sub_deal, claim_fee_bond, versioned_call.

Every tool returns one JSON envelope: tool, ok, sent, dryRun, refused[], error, summary, signer, disclaimer, data, plus optional warnings[].
